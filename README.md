# Portfolio Website, Dhia Sabri

Personal portfolio for **Dhia Sabri**, game designer & developer. Built with vanilla
HTML, CSS, and JavaScript, with no frameworks and no build step.

**Live site:** https://dhia-sabri.github.io

## Features

- Single-page layout with smooth-scroll navigation (About / Projects / Contact)
- Mobile hamburger drawer containing the links and the theme toggle
- Dark / light theme toggle, persisted in `localStorage`
- Infinite-looping project carousel with scroll-snap
- Glassmorphism styling, responsive from mobile to desktop
- Copy-to-clipboard email button
